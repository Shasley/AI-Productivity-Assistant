# 🧠 AI Workplace Productivity Assistant

## Project Overview

This project is a full-stack AI-powered productivity platform that enables users to automate common workplace workflows. It follows a modular architecture and modern SaaS UI principles.

---

## Core Features

### Email Generator

Creates structured, professional emails from user input.

### Meeting Summarizer

Extracts key points, decisions, and action items.

### Task Planner

Breaks goals into prioritized, actionable steps.

### Research Assistant

Generates structured summaries for any topic.

### Chat Interface

General-purpose AI assistant for workplace use.

---

## Tech Stack

### Frontend

* Next.js (React Framework)
* Tailwind CSS

### Backend

* Node.js
* API Routes

### AI Integration

* OpenAI GPT models

---

## Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Add Environment Variables

```env
OPENAI_API_KEY=your_openai_key
```

### 3. Start Development Server

```bash
npm run dev
```
